# Operation Ghostprint — OSINT Field Exercise

A 25–30 minute browser-only OSINT challenge for cyber training.

**Start:** Open [Mission Control](index.html) (or the GitHub Pages deployment).

**Scope:** This is a fictional intelligence incident. No real person is accused of wrongdoing. All real-world websites linked here are public research/reference resources, not targets.

## Rules of engagement
- Passive public research only. Do not contact, follow, message, or attempt to authenticate as any person.
- No scanning, brute force, exploitation, credential collection or interaction with third-party services beyond ordinary public browsing.
- Do not search for private information about unrelated individuals.
- Record source URLs and explain confidence levels.
- Don't assume a shared username proves identity.
- All evidence used to solve the scenario is provided on this site; external resources help verify OSINT methods.

## Deployment
Enable GitHub Pages for the repository's `main` branch, root directory. GitHub Pages may require repository settings changes by its owner. The challenge also works when `index.html` is opened locally.

**Instructor note:** No solution files are stored in this repository.
